## Premier lot appliqué

`isProductionRuntime()` considère maintenant Vercel comme un runtime de production, même si `NODE_ENV` est atypique. `getCurrentUserForAdmin()` n’ouvre plus le JSON local en production et renvoie une erreur contrôlée lorsque la base de production n’est pas disponible. `writeDB()` refuse toute écriture du stockage JSON local en production.

Ce lot est volontairement non destructif : il ne modifie aucune table, aucune donnée Supabase et aucune interface. Il transforme une écriture impossible sur disque en erreur explicite, ce qui permet de repérer les routes encore non migrées sans perte silencieuse.
